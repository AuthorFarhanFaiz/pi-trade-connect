# WooCommerce integration status

**Status: NOT IMPLEMENTED.** No installable WooCommerce plugin ZIP is available in this repository revision. Do not install this foundation as a payment plugin.

The planned integration must use WooCommerce's supported payment gateway APIs, provide merchant-configurable settings, verify payment server-side, map provider references to immutable order metadata, handle idempotency, and remain compatible with supported WordPress/WooCommerce versions and HPOS. It must not report success from browser callbacks alone. A later delivery should include plugin source, uninstall behavior, translations, automated/static tests, and a verified installable ZIP.

No claim of WooCommerce checkout compatibility or Pi Testnet verification is made.
